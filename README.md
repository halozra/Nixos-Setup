# ❄️ NixOS Configuration

A personal NixOS configuration managed with **Nix Flakes** and **Home Manager**, designed to be modular, reproducible, and easy to maintain.

This repository contains my daily NixOS setup, including system configurations, desktop environments, applications, and user-level configurations.

## ✨ Features

- **Nix Flakes** — Reproducible system configuration and dependency management.
- **Home Manager** — User environment management integrated at the host level.
- **Multiple Desktop Environments** — GNOME, KDE Plasma, and Hyprland.
- **Tokyo Night Storm** — Consistent system-wide theme.
- **Kitty & Fish** — Terminal emulator and shell configuration.
- **Modular Architecture** — Organized configuration using `hosts`, `modules`, and `apps` directories.
- **Hardware-specific Configuration** — Dedicated configurations for individual machines.

## 📋 Requirements

Before using this configuration, make sure you have:

- NixOS installed.
- Nix Flakes enabled.
- Git installed.
- Basic knowledge of NixOS and Home Manager.

## ⚠️ Before Installation

This repository is primarily designed for my personal hardware and user environment. Some configurations must be adjusted before using them on another machine.

### 1. Hardware Configuration

The following file contains hardware-specific settings:

```text
hosts/halozra/hardware-configuration.nix
```

It is automatically generated by NixOS and may contain:

- Partition UUIDs.
- Filesystem and mount point configurations.
- Bootloader-related hardware settings.
- CPU microcode configuration.
- Hardware-specific settings.

**Do not reuse my hardware configuration on another machine.**

Generate a new configuration for your hardware before rebuilding the system.

### 2. Username & Home Directory

This configuration currently uses the following username:

```text
halozra
```

And home directory:

```text
/home/halozra
```

Make sure to replace all occurrences of `halozra` and `/home/halozra` with your own username and home directory.

Pay special attention to Home Manager configurations and host-specific settings.

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/halozra/Nixos-Setup.git ~/Nixos-Setup
cd ~/Nixos-Setup
```

### 2. Generate Hardware Configuration

Generate a hardware configuration for your machine:

```bash
sudo nixos-generate-config --show-hardware-config > hosts/halozra/hardware-configuration.nix
```

This command writes the generated hardware configuration to the host directory.

Make sure the target file is correct and that you have a backup before replacing an existing configuration.

### 3. Configure Your Username

Search the repository for:

```text
halozra
```

Replace it with your own username.

Also update the home directory path:

```text
/home/halozra
```

For example:

```text
/home/your-username
```

Make sure all relevant configuration files are updated.

### 4. Add Changes to Git

Nix Flakes use Git-tracked files as their source.

After modifying the configuration, add the changes:

```bash
git add .
```

This ensures that newly created or modified files are available to the Flake.

### 5. Rebuild the System

Apply the configuration using the `halozra` host:

```bash
sudo nixos-rebuild switch --flake .#halozra
```

Wait for the build process to finish.

If your host configuration has a different name, replace `halozra` with the appropriate hostname defined in `flake.nix`.

## 🔄 Updating the Configuration

To update your local repository with the latest changes:

```bash
git pull
```

Then rebuild your system:

```bash
sudo nixos-rebuild switch --flake .#halozra
```

If you also want to update Flake dependencies, run:

```bash
nix flake update
```

Then rebuild the system.
